# Guilherme C. Mais | Portfólio

Este é o meu portfólio pessoal. Aqui eu conto quem sou, mostro minha experiência, as tecnologias com que trabalho e alguns projetos que desenvolvi.

Construí tudo com HTML, CSS e JavaScript puro, sem frameworks, para manter o código leve, fácil de entender e simples de manter.

## 🌐 Acesse

[guilhermecmais-delta.vercel.app](https://guilhermecmais-delta.vercel.app/)

## 🛠️ Tecnologias

- HTML5 semântico, pensado para acessibilidade e SEO
- CSS3 com variáveis organizadas no `:root` (cores, espaçamentos e tipografia)
- JavaScript puro (ES6+), em um único arquivo
- Google Fonts: Sora e DM Mono

## ✨ O que tem no site

- Seções que aparecem suavemente conforme você rola a página
- Linha do tempo de projetos, horizontal no computador e vertical no celular
- Seção de experiência
- Habilidades em badges, separadas por categoria
- Botões com uma animação discreta ao clicar
- Menu mobile que fecha com a tecla Esc e trava a rolagem enquanto está aberto
- Botão para voltar ao topo
- Formulário de contato com validação dos campos
- Layout responsivo para celular, tablet e computador
- Respeito à opção de reduzir movimento do sistema
- Conteúdo visível mesmo se o JavaScript não carregar

## 📌 Projetos em destaque

### MapsLink

Uma plataforma web de empregabilidade que conecta candidatos, estudantes e pequenas e médias empresas por meio de um mapa interativo. Desenvolvi em equipe, ao longo de 6 meses, como projeto acadêmico de caráter extensionista na PUC-Campinas. O projeto foi validado com usuários reais e publicado no GitHub Pages.

- Feito com HTML5, CSS3, JavaScript, Leaflet.js e Figma
- Filtros por setor, cidade e palavra-chave
- Arquitetura SPA, pronta para virar PWA
- Nota de acessibilidade acima de 95 no Lighthouse
- [Ver no GitHub](https://github.com/guimais/mapslink)

### Painel Comercial

Um painel de controle de leads que criei para a área comercial de uma empresa júnior de consultoria. Ele ajuda a acompanhar o pipeline, os SLAs, a receita esperada e o desempenho dos membros da área.

- Feito com HTML5, CSS3 e JavaScript puro
- Filtros por status, responsável, mês e ano
- Layout responsivo
- [Ver no GitHub](https://github.com/guimais/painel-comercial)
